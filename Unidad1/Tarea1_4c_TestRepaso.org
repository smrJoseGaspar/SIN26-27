* Bloque 1: Componentes Físicos e Interconexión (CE 1.a)

1. *¿Cuál es la función principal del chipset (PCH) en una placa base moderna?*
   - [ ] a) Ejecutar las instrucciones aritmético-lógicas de los programas de usuario.
   - [ ] b) Gestionar las comunicaciones entre el procesador, las ranuras de expansión y los periféricos de E/S.
   - [ ] c) Convertir la corriente alterna de la red eléctrica en corriente continua de 12V y 5V.
   - [ ] d) Almacenar de forma volátil los datos de las aplicaciones abiertas.

2. *¿Qué interfaz física ofrece actualmente mayor ancho de banda para una unidad SSD de alto rendimiento?*
   - [ ] a) SATA III (6 Gbps).
   - [ ] b) USB 3.2 Gen 1.
   - [ ] c) Ranura M.2 conectada mediante bus PCI Express x4 NVMe.
   - [ ] d) Puerto IDE / PATA de 40 pines.

3. *¿Qué conector de la fuente de alimentación suministra energía dedicada directamente al procesador en la placa base?*
   - [ ] a) Conector ATX principal de 24 pines.
   - [ ] b) Conector EPS / ATX12V de 4+4 (8) pines.
   - [ ] c) Conector PCIe de 6+2 pines.
   - [ ] d) Conector SATA de 15 pines.

* Bloque 2: Jerarquía y Tipos de Memorias (CE 1.b)

4. *Ordena los siguientes tipos de memoria de MAYOR a MENOR velocidad de acceso (menor latencia):*
   - [ ] a) Caché L1 > Registros CPU > Memoria RAM > SSD NVMe.
   - [ ] b) Registros CPU > Caché L1 > Memoria RAM > SSD NVMe.
   - [ ] c) Memoria RAM > Registros CPU > Caché L2 > Disco Duro HDD.
   - [ ] d) Registros CPU > Memoria RAM > Caché L1 > Memoria Flash UEFI.

5. *¿Cuál de las siguientes memorias es NO volátil y almacena el firmware encargado de iniciar el hardware del equipo?*
   - [ ] a) Memoria DRAM DDR5.
   - [ ] b) Memoria Caché L3 (SRAM).
   - [ ] c) Memoria Flash ROM (UEFI/BIOS).
   - [ ] d) Registros de propósito general.

6. *¿Qué ventaja principal aporta instalar dos módulos de memoria RAM idénticos en configuración Dual Channel?*
   - [ ] a) Duplica la capacidad total de almacenamiento del disco duro.
   - [ ] b) Duplica el ancho de banda de comunicación entre la RAM y el controlador de memoria.
   - [ ] c) Convierte la memoria RAM en memoria no volátil ante cortes de luz.
   - [ ] d) Reduce a cero la latencia CAS de los módulos.

* Bloque 3: Proceso de Puesta en Marcha (CE 1.c)

7. *¿Qué ocurre exactamente durante la fase POST (Power-On Self-Test) al encender un ordenador?*
   - [ ] a) Se carga el escritorio del sistema operativo desde la nube.
   - [ ] b) El firmware verifica la integridad y presencia de componentes críticos (CPU, RAM, GPU) antes de buscar un dispositivo de arranque.
   - [ ] c) Se formatea automáticamente la partición primaria del disco duro.
   - [ ] d) Se actualizan los controladores de la impresora y la tarjeta de red.

8. *Si al pulsar el botón de encendido los ventiladores giran pero no hay señal de vídeo y la placa base emite una secuencia de pitidos largos o enciende el LED "DRAM", ¿cuál es el diagnóstico más probable?*
   - [ ] a) El cable Ethernet no está conectado al router.
   - [ ] b) Fallo de detección, mala colocación o incompatibilidad en los módulos de memoria RAM.
   - [ ] c) El sistema operativo tiene un virus en el sector de arranque.
   - [ ] d) La pasta térmica del procesador está caducada.

9. *¿Para qué sirve activar un perfil XMP (Intel) o EXPO (AMD) dentro de la configuración UEFI/BIOS?*
   - [ ] a) Para cifrar el contenido del disco duro con contraseña.
   - [ ] b) Para permitir que los módulos RAM funcionen a su frecuencia y latencias nominales anunciadas por el fabricante en lugar de la velocidad base JEDEC.
   - [ ] c) Para desactivar los núcleos de eficiencia del procesador.
   - [ ] d) Para arrancar el equipo directamente desde un servidor remoto por red (PXE).

    - [ ] b) Periférico exclusivamente de entrada.
    - [ ] c) Periférico mixto de entrada/salida (E/S).

    - [ ] a) El gestor de arranque (GRUB / Windows Boot Manager).

    - [ ] a) Duplicar pantalla.
    - [ ] b) Solo segunda pantalla.

* Bloque 5: Seguridad y Prevención de Riesgos Laborales (CE 1.h)

13. *¿Cuál es la medida preventiva más eficaz para evitar daños por descarga electrostática (ESD) al manipular una placa base o memoria RAM en el taller?*
    - [ ] a) Trabajar sobre una alfombra de lana con el equipo enchufado.
    - [ ] b) Desconectar el cable de alimentación, descargar energía residual y utilizar pulsera antiestática conectada a tierra.
    - [ ] c) Tocar directamente los pines dorados de los módulos para comprobar su temperatura.
    - [ ] d) Utilizar guantes de látex gruesos sin conexión a tierra.

14. *Según las recomendaciones de ergonomía laboral en puestos con pantallas de visualización de datos (PVD), ¿cómo debe situarse el borde superior del monitor respecto al usuario?*
    - [ ] a) A la altura de los ojos o ligeramente por debajo, a una distancia aproximada de 50-70 cm.
    - [ ] b) Unos 30 cm por encima de la cabeza para ejercitar el cuello.
    - [ ] c) Pegado a menos de 20 cm del rostro y con brillo al máximo.
    - [ ] d) Orientado directamente frente a una ventana sin cortinas para recibir luz solar directa en la pantalla.

15. *¿Cómo debe gestionarse una fuente de alimentación averiada o una placa base obsoleta según la normativa medioambiental vigente?*
    - [ ] a) Depositándola en el contenedor amarillo de envases ligeros.
    - [ ] b) Tirándola al contenedor de residuos orgánicos.
    - [ ] c) Gestionándola como Residuo de Aparatos Eléctricos y Electrónicos (RAEE) a través de un punto limpio o gestor autorizado.
    - [ ] d) Desmontando los condensadores y tirándolos por el desagüe.
